# Plektra branding

- `plektra-open-color.svg` is the canonical orange mark.
- `plektra-nightly-open-color.svg` uses the same geometry with the Nightly blue accent.
- The framed forms are the source for legacy launcher bitmaps.
- `plektra-open-monochrome.svg` is the source for themed Android icons.
- `main-activity-preview.svg` records the intended quiet header treatment before device-specific rendering.

Do not alter the geometry independently between Stable and Nightly.

`opencollective-button.png` is the official Open Collective donation button, obtained from `https://opencollective.com/plektra/donate/button@2x.png?color=blue`. Open Collective licenses its button designs under CC BY-SA 4.0; the logo is its trademark. See https://documentation.opencollective.com/collectives/raising-money/adding-donation-buttons-badges-and-banners.
